# BeautyAI 협업일지

공식 8항목 일지, 전체 TODO, 완료 수와 진행률 바를 한 날짜 폴더에 묶는다. 프로젝트 위치와 브랜치는 [project.json](references/project.json)을 읽어 확인한다.

## 기록 기준

- **공유용과 실제 체크를 분리한다.** 날짜별 전체 TODO는 읽기용 스냅샷이다. 실제 구현 체크는 코드 브랜치의 원본에서 관리하고, 공유 날짜에 맞추려고 원본 체크를 되돌리거나 미리 체크하지 않는다.
- **전체 수를 130개로 고정하지 않는다.** 고정한 원본의 항목이 늘면 분모와 기준 커밋을 함께 갱신하며 이전 날짜의 수치는 보존한다.
- 본문은 날짜/이름/팀, 역할·작업, 당일 완료도, 제안·피드백, 인사이트·문제, 일정·협업 어려움, 발표·소통 기여, 다음 목표 순서의 8항목으로 쓴다.
- **전체 TODO는 모두 표시한다.** 이후 예정도 계획 목록에는 보여주되 일지에서는 미리 체크하거나 완료 성과로 서술하지 않는다. 보고일 범위에서 끝난 항목만 전부 체크한다.
- 원본 체크·근거, 계획일, 완료일을 대조한다. 단계에 날짜가 여러 개면 기존 프로젝트 기준인 단계 시작일을 사용하고 표기한다. 일정 불명은 단정해 완료로 세지 않는다.
- 원본 TODO는 구현 상태의 기준이다. 일지는 보고일 기준 관측이므로 날짜를 맞추려고 원본 체크나 완료일을 고치지 않는다.
- 진행률 분모는 원본 한 곳의 전체 체크 수, 분자는 보고일에 포함 가능한 완료 체크 수다. 일지·요약·별첨을 다시 세지 않는다. 이후 예정 완료는 분자에 넣지 않는다.
- 이 수치는 **일지 체크 기준**이다. 제품·실제 코드 완성률과 다르며 당일 자기평가(0/25/50/75/100%)를 자동 진행률로 바꾸지 않는다.
- 외부 API와 SSOT 연결은 따로 묶어 보여준다. 로컬 실험을 외부 API 성공·실제품 품질·팀 인수 완료로 바꾸지 않는다.

## 생성

1. 저장소·remote·브랜치·작업 중인 변경을 확인한다. 원격 ref를 fetch해 SHA를 고정한다. 진행 중인 코드와 공유 checkout은 수정하지 않는다.
2. TODO와 검증 문서·체크 날짜를 확인한다. 미게시 WIP는 완료로 합산하지 않는다. 일정 매핑이 필요하면 명시적인 JSON을 준비하며 분자를 키우려고 날짜를 앞당기지 않는다.
3. 다음 도구로 전체 목록과 정적 진행률 이미지를 만든다. Git은 읽기만 하며 출력 폴더의 알려진 4개 파일만 쓴다.

    python3 scripts/build_progress.py --repo /실제/저장소 --ref origin/plan/models --source docs/imageTodo.md --date YYYY-MM-DD --out /임시/새출력폴더

   경로는 스킬 폴더 기준이다. 선택 옵션 --schedule-map은 항목 ID 또는 섹션 이름을 ISO 날짜에 매핑한다. --overwrite는 기존 생성물 갱신을 명시한다.
4. full-todo.md, full-todo.html, progress.svg, progress.json을 날짜별 일지 옆에 둔다. 일지 2번 항목과 README에서 **전체 목록과 진행률 바**를 연결한다. HTML에는 실제 progress 요소, Markdown에는 SVG 이미지를 넣는다.
5. 스키마 상세는 별첨으로 보존한다. 감정·자기평가·팀 수신·합의를 지어내지 않는다. 자기평가가 없으면 잠정임을 표시한다.
6. 한국어를 담백하게 다듬고 수치·날짜·상태를 확인한다. 교육자료 원문과 예시 답변은 공개 복제하지 않는다.

## 게시와 확인

사용자가 요청한 경우에만 박지수_협업일지 브랜치에 일반 push한다. PR·병합·force push는 하지 않는다. 다른 작업자의 변경이 있으면 임시 index나 허용된 격리 경로를 쓰고 공유 index/checkout을 보존한다.

원격 SHA와 파일을 대조하고 README 링크를 눌러 8항목·전체 수·체크 수·진행률 바를 확인한다. HTML과 Markdown 숫자가 같아야 한다. 그림이나 HTTP 200만으로 끝내지 않는다.

모델 호출·서버 재시작·Discord/Notion 전송·예약은 이 스킬만으로 승인되지 않는다.
