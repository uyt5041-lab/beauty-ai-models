- [plan/models](https://github.com/uyt5041-lab/beauty-ai-models/tree/plan/models): 모델 참고 코드·문서·테스트를 관리하는 기본 브랜치입니다.

- 원본 Git 이력과 작업 당시 기록을 보존했습니다. 과거 PR 상태·브랜치 이름은 당시 기록이며, 본문의 이전 안내에 현재 위치를 표시했습니다.
