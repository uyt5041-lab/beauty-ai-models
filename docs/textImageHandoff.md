# 텍스트 → 이미지 연결 · 2026-10-28

기준: [다혜님 VLM 연동 문서](https://app.notion.com/p/VLM-406b13f77dbd8022a12ecbc41e584f8f), 사용자 전달 답변 및 구현 요청. 이것은 Python 수신 계약이다. 팀 HTTP 경로를 확정하지 않는다.

## 담당

김다혜는 제품 분석·기획·카피·한국어 이미지 프롬프트·검수를 구현한다. `OpenAITextGateway`와 `ReviewService`는 이 저장소의 과거 참고 구현이다. 새 이미지 연결에서 생성하거나 호출하지 않는다. pi는 분석 결과 수신·이미지 API·결과 저장·크기 변환·최종 합성을 맡는다. 서빙은 자산 소유권·분석 단계 차단·사용자 승인·팀 예산을 연결한다.

## 입력과 변환

`product_analysis`는 다혜님의 `ProductAnalysisResult`를 dict로 전달하는 필수 입력이다. 객체를 전달할 때는 다혜님 모델의 `model_dump()` 결과를 사용한다. `analysis`·`analysis_succeeded`·`error`를 수신한다. 용기 형태에는 `어플리케이터`와 `스틱`이 포함된다. 원시 error는 메모리에서 수신만 하고 이미지 요청·저장 snapshot·사용자 오류·기본 repr에서 제외한다. 오류 상세 보관은 서빙의 비공개 로그 정책을 따른다.

`image_prompt={concept, prompt, mood}`의 prompt는 다혜님 한국어 원문이다. `positive`에 원문·콘셉트·광고 무드를 넣고 `negative=""`, `language="ko"`로 내부 변환한다. 원문을 영어로 번역하지 않는다. `product_description`·`creative_direction`이나 프리셋 선택은 요구하지 않는다. 기존 3개 영어 프리셋은 과거 비교 실험 전용이다.

분석의 product_type·container_type·colors·is_transparent·mood는 **AI 관찰 참고값**으로 별도 표시한다. 광고 무드는 image_prompt.mood이고, 분석의 mood가 덮어쓰지 않는다. 사진과 사용자 확인 정보가 우선이다. label_text는 잘못 읽을 수 있으므로 생성 프롬프트나 광고 문구로 복사하지 않는다. 효능·성분을 추정하지 않는다.

제품 사진은 2~5장, 첫 사진이 정면·주 시점이다. 배경 참고는 별도 0~5장이다. 순서를 보존하며 정면 자동 판별은 하지 않는다. VLM 내부 긴 변 1536px 축소는 분석 전용이다. 서빙은 생성용 원본을 별도로 전달한다. 이미지 입력에는 기존 크기/용량 제한이 적용된다.

## 실패 차단과 재사용

분석 성공 여부를 먼저 확인한다. `analysis_succeeded=false`이면 실패 기본값의 is_cosmetic 값과 관계없이 `PRODUCT_ANALYSIS_FAILED`로 차단한다. 성공했으나 is_cosmetic=false이면 `PRODUCT_NOT_COSMETIC`으로 차단한다. 누락·잘못된 bool·스키마 오류도 통과하지 않는다. 거절은 자산 저장·요청 결속·비용 예약·API 호출 전에 수행한다. 이미지 모델에서 재분석하거나 자동 재시도하지 않는다.

분석 snapshot은 이미지 요청과 같은 입력 지문에 결속한다. 같은 job의 분석·사진·프롬프트가 달라지면 새 요청으로 몰래 재생성하지 않고 충돌로 거절한다. 새 계약은 새 job으로 실행한다. 이전 job의 영수증은 조회 전용 경로로 유지한다. 분석 결과와 사진이 실제 같은 입력인지는 서빙에서 검증해야 하며 bool 전달만으로 증명되지 않는다.

## 한국어 공통 정책과 호환성

새 서비스 요청은 `cosmetics_policy_version=ko-v1`로 제품 보존·사진 순서·광고 글자 여백·워터마크 제외 조건까지 한국어로 조립한다. 언어 표시는 문자 자동 판별이 아니다. 제품 영문명 등 원문을 강제 번역하지 않는다. 과거 요청의 필드·프롬프트 해시는 바꾸지 않고 한국어 버전 식별자로 새 경로를 구분한다. 기존 영어 Langfuse 버전도 덮어쓰지 않는다. 새 한국어 정책의 원격 Langfuse 게시·실제 품질 평가는 이번 구현에 포함하지 않는다.

`resize_ad_png`는 4:5 입력을 원본과 별도로 1080×1350 PNG로 축소한다. 크롭·늘이기·확대는 하지 않는다. PNG 압축은 무손실이지만 축소 자체는 픽셀 정보를 줄인다. 글자 레이어를 쓸 경우 최종 크기 변환 후 한글을 합성한다.
