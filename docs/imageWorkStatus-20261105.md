## 자유형 다수+합성형1장 — 구현 보류

총2/3/4장 선택은자유형:합성형1:1/2:1/3:1. 총1장은 단독 방식 선택을 제안했다. 자유형은 모델이 광고문구까지 그리는 방식이라는 정의를 먼저 팀에서 확인해야 한다.

| 담당 | 할 일 |
|---|---|
| 프론트 | 장수·방식·비율 선택, 구성/비용 안내, 후보별 상태·선택·승인·다운로드 |
| 서빙 | 서버 장수 계산·실행묶음/후보ID·상태·예산·동시성·중복요청·승인·미확인 대조 종결 |
| 이미지 | 후보1개씩n=1, 자유형/합성형 정책 분리, 공통 보존/호출가드/원장/크기변환, 합성형만 로컬 글자 합성 |
| 텍스트 | 제품 분석·기획·카피·검수 결과 공유, 자유 광고용/배경 전용 프롬프트 문안 구분 |
| PM | ‘제작 방식 비교 생성’ 고도화 범위·담당·선행 계약·완료 기준과 미확정 사항 정리 |

금붕어5단계 독립 리뷰에서 미확인 호출 종결 책임·대안 근거·합성형 API 비용 표현3건을 찾아 수정하고 수리 확인했다. 분담 논의에는 사용할 수 있지만 상세 요청/후보/승인/예산 계약·정확한 변경파일·테스트 명세가 미정이므로 구현 준비 판정은NEEDS_DECISION이다. 사용자가 이번 안건을 보류하라고 요청해 구현하지 않았다.

합성형도 배경/제품 생성에는 이미지 API를 사용하고, 이후 글자 합성만 로컬이다. 미확인 호출은 이미지가 증거를 제공하고 서빙이 상태·예산 예약 종결을 총괄한다. 텍스트 검수 통과를 자유형 이미지 속 글자 검수 통과로 바꾸지 않는다.
