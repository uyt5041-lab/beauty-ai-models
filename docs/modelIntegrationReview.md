MVP 연결 순서는 **입력 → 사전 조사·기획 → 카피 1개 → 사용자 카피 검토 → 이미지 1개 → 사용자 이미지 검토 → 한글 합성 → 최종 이미지와 본문·해시태그 출력**이다. 자동 위험 검수는 사용자 검토에 필요한 정보를 제공하며 사용자 선택 자체를 대신하지 않는다. 복수 시안, 사용자 부분 수정, 병렬/역순 생성 실험은 SSOT의 MVP 후 고도화 범위로 구분한다. 이미 있는 재작성·캐시·revision 기능을 없애라는 뜻은 아니다.
