# 11월 3일 이미지 고도화 체크와 협업 현황

기준: 2026-11-03 19:28 KST까지 확인한 자료. [11/02 팀 회의록](https://app.notion.com/p/2026-11-02-40cb13f77dbd80d3be9cf3219d4bf590)을 11/03 로그인된 브라우저에서 확인했다. 회의록의 최종 선택 목록 **7개 + 추가 프리셋 + 미래 계획 3개**를 따른다. 앞쪽의 전체 후보 11개와 최종 선택 목록을 혼합하지 않는다.

이 문서는 상태 점검이다. 로컬 구현, 원격 게시, 서비스 반영, 품질 인수는 각각 구분한다. 아래 미체크는 이미지 담당 범위의 최종 인수 전이라는 뜻이며, 다른 담당의 최신 코드가 없다는 판정이 아니다. 새 기능을 구현하거나 유료 API를 호출한 기록 작업이 아니다.

## 오늘 끝낸 확인·실험

- 초기6장 → R/E 비교12장 → E2 6장과 실측R2 6장을 이력30건으로 묶었다. 이30건은 해당 비교 묶음의 크기이며 프로젝트 전체 호출 수가 아니다. R은 원본 제품 사진+광고 참고+수정 프롬프트로 새 생성, E는 이전 생성물+원본 제품으로 편집한다.

## 협업에서 반영한 피드백

Vita B·잡티로즈쎄럼 및 실제 광고를 완성도 참고로 사용하고, 고정A 배치에 제한하지 않는 별도 실험으로 진행했다. 테마의 색·재질·소품·조명·구도와 서체 변주를 구분해 검토했다. 이 실험은 운영의 분리 합성·승인 계약을 교체한 것이 아니다.

사용자·팀원은T4~T6의 제품이 **두꺼워 보이는 문제**를 지적했다. 이를 얇아짐으로 잘못 해석하지 않도록 기록을 정정하고 폭·길이·캡 비율 보존을 보강했다. R2를 선호한다는 사용자 피드백은 기록하되 정량 제품 보존 합격과 구분한다. T6 하단 좁아짐/둥근 바닥, 인물 손·작은 글자 정확도는 검토를 남긴다.

실험 CTA `새로운 색상 보러가기`는공백 포함11자이며 사용자가 이번 실험에 지정했다. 기존 팀MVP의CTA10자 합의를 자동 변경하지 않는다. 운영 적용 전 문구/한도를 Text와 다시 맞춘다. 이미지 쪽이 카피·규제 검수를 중복 수행하지 않는다. 사용자에게 설명한 것과 팀원에게 실제 전송·수신한 것은 구분하며, 이번에는 직접 메시지를 보내지 않았다.
