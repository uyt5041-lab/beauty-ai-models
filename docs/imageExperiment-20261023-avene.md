## 실행 결과

- 입력: iCloud에서 확인한 아벤느 Cicalfate+ 100ml의 정면·측면·뒷면. 참고 사진은 0장이다.
- 형식: 공유 사진은 JPG 확장자의 MPO였다. 원본을 보존하고 frame 0을 PNG로 옮겼다. 파일 검사와 픽셀 비교는 별도로 새로 열어서 진행했다. 3장 모두 통과했다.
- 미리보기: 입력 역할·최종 프롬프트·프리셋·버전·호출 상한·파일 연결을 확인했다. 브라우저의 로컬 파일 접근은 차단되어 HTML과 사진을 로컬 파일 도구로 확인했다. 브라우저 표시 검증은 하지 않았다.
- 프리셋: `vivid_pop`. Langfuse `beautyai/cosmetics/vivid-pop` 버전 1을 사용했다. 새 프롬프트 버전은 만들지 않았다.
- 모델: `gpt-image-2.5-sunburst-2026-09-08`. 결과는 1152×1440, 4:5다.
- 실행: 승인된 상한 1회에서 실제 1회 성공했다. 이후 평가와 W&B 기록 중 이미지 API를 다시 호출하지 않았다.
- 시간: 27.393523초. 내부 작업 제출·조회·결과 다운로드 범위다. 서비스 전체 시간과 p95는 아니다.

## AI 예비 평가

| 항목 | 가중치 | 점수 | 관찰 |
|---|---:|---:|---|
| 형태 보존 | 25% | 3/5 | 튜브가 원본보다 가늘고 길게 정돈되고 캡 비중이 커 보인다. 원근 차이가 있어 치수 오차율로 단정하지 않는다. |
| 로고·라벨 | 25% | 4/5 | 주요 브랜드·제품명·용량은 보인다. 작은 글자와 획의 완전 일치는 미확인이다. |

| 광고 콘셉트 | 15% | 5/5 | 밝은 코발트·코랄과 제품 1개 조건을 충족한다. |

## 비용과 FinOps

실제 응답 사용량은 입력 글 524토큰, 입력 이미지 4,356토큰, 출력 418토큰이다. 2026-10-23 확인한 표준 직접 이미지 API 요금으로 추정했다.

`(524 × 5 + 4,356 × 8 + 418 × 30) / 1,000,000 = $0.050008`

근거: [모델 요금](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst), [이미지 생성 안내](https://developers.openai.com/api/docs/guides/image-generation). 이번 1회 호출만 포함한다. 다른 서비스 비용과 세금은 포함하지 않는다. 예약 예산 $1은 청구액이 아니다. 실제 청구액은 `null`, 대조 상태는 `UNRECONCILED`다.

FinOps 비중은 **40%**다. 이미지 품질 40%, 서비스 20%다. 실제 청구액·팀 잔액·승인된 최종 광고가 없어 FinOps와 서비스 전체 점수는 계산하지 않았다. 이번 연구용 생성 비용을 운영 낭비율의 표본으로 사용하지 않는다.
