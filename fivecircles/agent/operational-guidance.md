# 운영 초기화

1. 실제 작업 폴더·브랜치·remote·기존 변경을 확인한다. Git 폴더가 아니면 Git 명령을 실행하지 않는다.
2. `fivecircles/README.md`와 관련 요구사항/계약을 읽는다.
3. 역할·선택 TODO·완료 기준·필요한 검증을 확인한다.
4. 변경 전 영향과 미합의 조건을 알리고 작은 배치로 진행한다.
5. 작업 후 원본 TODO, update, 검증 결과를 맞춘다. 기록 파일에 API 키/모델 응답 전체/개인정보를 남기지 않는다.

두 폴더가 존재할 수 있다. 사용자 로컬 beautyAi는 소스 복사본, plan/models checkout은 Git 관리 폴더다. `.git`을 복사하거나 소스 전체를 덮어쓰지 않는다. 이 프레임워크 설치 시 공통 설정만 양쪽에 반영했다.
