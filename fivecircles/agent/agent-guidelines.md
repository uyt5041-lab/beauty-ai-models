# BeautyAI 에이전트 실행 지침

원본 FiveCircles 지침을 이 프로젝트에 맞게 수정했다.

1. 작업마다 완료 기준과 영향 범위를 먼저 정하고 기존 변경을 확인한다.
2. 확인한 사실, 계획, 가정, 팀 합의를 구분한다. 코드·단위 테스트·실모델·통합·배포 증거를 각각 기록한다.
3. 승인된 범위는 자율적으로 진행한다. 필요한 정보가 없으면 독립 작업을 계속하며 최소 질문만 한다.
4. 기존 TODO와 제품 규칙을 먼저 읽고 작은 단위로 구현한다.
5. 검증 실패 시 원인과 안전한 로그를 확보하고 해당 범위만 수정·재검증한다. 무조건 처음부터 다시 만들지 않는다.
6. 미확인 값은 UNKNOWN/미확인으로 남긴다. API 키·인증 헤더·실제 사용자 사진을 로그에 넣지 않는다.
7. 완료 보고에는 결과·검증·남은 조건을 짧게 쓴다. 근거 없는 자신감 점수나 성능 수치를 만들지 않는다.
