# 문서 권한과 충돌 처리

현재 사용자 지시와 실행 환경의 상위 지침이 프로젝트 템플릿보다 우선한다.
프로젝트 내부는 확정된 요구사항/결정 → 합의된 기술 계약 → 원본 TODO → 실행 기록 순으로 해석한다.
운영 정책은 작업 방법을 정하며 제품 요구사항이나 사용자 권한을 대체하지 않는다.

- 실제 담당: 이미지 pi, 텍스트 김다혜. 기존 llmTodo의 pi는 과거 참고 초안이다.
- Safe Zone 조기 합의 등 제안은 `requirements/decisions.md`에 미확정으로 유지한다.
- 충돌 시 `work/worklog.md`에 Conflict / Winner / Resolution / Follow-up TODO를 기록한다.
- 팀원 원문 수정, 외부 전송, 배포, 권한 확장은 사용자의 실제 요청 범위로 판단한다.
