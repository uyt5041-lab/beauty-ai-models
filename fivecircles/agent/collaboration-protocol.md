# BeautyAI 담당과 협업

| 담당 | 책임 | 다른 파트와의 경계 |
| --- | --- | --- |
| pi | 누끼·마스크·배경·원본 제품 재합성·이미지 품질·모델 실행 | 영어 프롬프트의 모델 적합성 검증, 텍스트 생성기 중복 구현 금지 |
| 김다혜 | 제품 관찰·콘셉트·카피·영어 이미지 프롬프트·문구 검수 | 이미지 pixel/레이아웃 승인을 대신하지 않음 |
| API/자산/렌더러 담당(미확정) | 업로드 검증·영속 job·승인·좌표 조립·내보내기 | 담당자 이름과 실행 환경은 합의 후 기록 |
| 작업 에이전트 | 현재 사용자가 요청한 범위의 설계·구현·검증·기록 | 모델 이름으로 권한을 고정하지 않음 |

- 실제 원본 TODO는 [이미지](../../docs/imageTodo.md), [LLM 참고 초안](../../docs/llmTodo.md), [연동 점검](../../docs/modelIntegrationReview.md)을 사용한다.
- 같은 파일은 한 작성자가 편집한다. 독립 파일 작업과 읽기 전용 검토를 병렬화한다. 공유 schema 변경은 담당 범위를 먼저 조율한다.
- `sync.md`는 현재 작업/근거를 남기는 문서다. 메시지 전달·상대 수신·합의를 증명하지 않는다.
- `queue.json`은 보조 작업 목록이다. 상세 체크 상태의 원본은 docs이며 자동 실행/주기 감시 기능은 없다.
- 요청 → 진행 → 검토 → 완료 상태를 사용하되, 실제 사용자 중단 요청은 즉시 보존·중단한다.
- 10/26 기본 Safe Zone·영어 프롬프트·hash 계약은 조기 합의 제안이다. 10/30 M1 전에 합의되지 않으면 통합 위험으로 남긴다.
- 11/6은 이미지 M2, 11/10은 팀원 텍스트 최종 고정 계획이다. 이후 계약/프롬프트 변경은 영향 범위 회귀를 수행한다.
