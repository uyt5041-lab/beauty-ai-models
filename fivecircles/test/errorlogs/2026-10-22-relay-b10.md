# B10 출력 검증 경고 분류 수리

- 발생: 2026-10-22, 정확한 발생 시각은 별도 측정하지 않음. 기록: 2026-10-22 19:38 KST.
- 범위: OpenAI 모의 PNG 응답 검증. 실제 API 호출 없음.
- 재현: 작은 PNG의 IHDR를 10000×10000으로 바꾸고 CRC를 갱신한 응답. Pillow `DecompressionBombWarning`은 `UserWarning`과 별도 계열이어서 출력 오류 검사에서 누락됐다.
- 영향: 경고를 오류로 취급하는 환경에서 응답을 이미 받았는데 `PROVIDER_SUBMISSION_UNKNOWN`으로 기록할 수 있었다. 유효 결과 게시나 자동 재호출은 발생하지 않았다.
- 수정: 명시적인 `Image.DecompressionBombWarning` 필터와 예외 처리를 추가했다. `PROVIDER_OUTPUT_INVALID` / `failed` / `RESPONSE_RECEIVED`로 기록하고 결과를 공개하지 않는다. 예약액은 유지한다.
- 재검증: `tests/test_api_image_processor.py`와 `tests/test_provider_attempts.py` 30 tests PASS. 최종 전체 회귀는 [B10 검증](../relay-b10.md)에 기록한다.
