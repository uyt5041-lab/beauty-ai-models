# B12 검증 중 오류와 수정 · 2026-10-23

- 비교 실행기 신규 테스트 2개가 짧은 내부 인증 토큰 fixture로 앱 생성 전에 실패했다. 운영 설정을 바꾸지 않고 fixture를 32자 이상으로 수정했다. 이후 신규 11개와 전체 934개 통과.
- Langfuse observations의 기본 응답에는 promptName이 없어서 readback 확인 스크립트가 중단됐다. 필드 그룹 `core,basic,usage,metadata,prompt,io`를 명시해 다시 조회했다. 3개 관찰의 프롬프트·해시·사용량 일치 확인. 이미지 API를 재호출하지 않았다.
- 문서 링크 검사를 증거 파일 작성 전에 실행해 B12 링크가 아직 없다는 결과가 나왔다. 검증 기록 파일을 추가한 뒤 재검사 PASS.
- 재발 방지: 관찰 조회는 필요한 필드를 명시하고 allowlist로 저장한다. 추적 실패를 이미지 재시도로 연결하지 않으며 CLI/SDK 원문 오류·키를 출력하지 않는다.

- 로컬 beautyAi 가상환경은 SDK 선택 의존성이 없었다. Git 작업환경의 설치 상태를 로컬과 동일하다고 가정하지 않고 `.[test,observability]`를 로컬에도 설치한 뒤 신규 68개 PASS(7.04s), pip check PASS를 확인했다.
