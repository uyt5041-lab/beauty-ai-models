# 현재 요구사항

## 제품

화장품 광고 생성 MVP의 텍스트/이미지 모델 계약과 구현을 실제 서비스에 연결한다.
2026-10-22 사용자 정정에 따라 **텍스트 담당 김다혜는 LLM·관찰·카피·영어 프롬프트, 이미지 담당 pi는 외부 이미지 API 래퍼·제품 보존·이미지 품질**을 맡는다. 이미지 제공자·모델은 미정이며 리서치 후 선정한다. 외부 API 어댑터는 아직 구현하지 않았다. 로컬 BiRefNetLite/SDXL은 실험 자료로 보존하며 자체 GPU 구축·튜닝·GCP CUDA 이전은 MVP 필수 조건에서 제외한다. 최종4:5·한글 합성·사용자 검토·참고 배경 구도 등 SSOT 기능 목표는 유지한다.

2026-10-22 사용자에게 받은 SSOT 문서 `401b13f77dbd80f39bbccd2e3a489566`를 MVP 목표의 대조 기준으로 사용한다. 수신본 SHA-256·현재 구현과의 차이·인수 조건은 [SSOT 대조 및 전달 기준](../../docs/ssotAlignment.md)에 기록한다.

- 동일 제품 사진 2~5장과 선택 배경 참고 사진 0~5장을 입력받는다. 배경의 모습과 구도 활용이 목표다. 세부 제품 카테고리 사전 선택을 요구하지 않는다.
- 기획 사전 조사 → 콘셉트·카피 1개 → 사용자 카피 검토 → 이미지 1개 → 사용자 이미지 검토 → 한글 카피 합성의 직렬 흐름을 목표로 한다.
- 최종 인스타그램 피드 광고 1개는 4:5이며, 캡션·해시태그와 확인·다운로드를 제공한다. 모델 작업 캔버스와 최종 출력 비율은 구분한다.
- 입력 용량·해상도 무제한이라는 SSOT 요구와 현재 20MiB·1,600만 픽셀 안전 상한 사이에는 운영 합의가 필요하다. 기존 가드를 자동 제거하지 않으며, 이 요구를 출력 비율 제한 없음으로 해석하지 않는다.
- 기존 누끼·제품 보존·제품 레이어 승인·ledger·요청 hash·유효 결과 캐시는 유지한다. 생성 후 사용자 이미지 검토·최종 한글 렌더는 별도 구현이다.
- 부분 수정 UI·다중 시안·3:4와 비율 선택은 후속이다. 실행 체크리스트의 원본은 [imageTodo.md](../../docs/imageTodo.md) 하나로 유지한다.

사용자 요청에 따라 SSOT-01~12의 차이·목표·변경 작업·담당/미정·의존성·완료 기준을 [대조 문서](../../docs/ssotAlignment.md)와 기존 TODO에 연결한다. 이 문서 작업은 B9 종료 게이트를 건너뛰는 후속 구현이 아니며 추가 코드·모델 호출을 포함하지 않는다. HTML 검증 제한을 기존 승인된 소스·문서 게시 금지로 확대하지 않고, 최종 Git 게시 증거는 별도 갱신한다. 브라우저 우회와 릴레이 다음 구현은 진행하지 않는다. 원문 파일·개인 경로·계정 정보는 공개 저장소에 복사하지 않는다.
