## 2026-10-22 전달 SSOT의 MVP 기준

출처는 사용자에게 받은 SSOT 문서 ID `401b13f77dbd80f39bbccd2e3a489566`다. 수신본 SHA-256과 항목별 현재 구현·목표·담당/미정·인수 기준은 [ssotAlignment.md](../../docs/ssotAlignment.md)에 기록한다. 원문 파일·개인 경로·계정은 공개하지 않는다. 전달 자료에 명시된 목표와 실제 구현·팀원 수락을 구분한다.

- **SSOT-01~04:** 동일 제품 사진 2~5장, 배경 참고 사진 0~5장과 구도 활용, 최종 광고 4:5가 목표다. 기존 로컬 경로는 단일 source·SDXL 각 축 512/768/1024이고 VLM은 아직1~3장이다. B10 이미지 edit 계약은 제품 최대5장·참고 최대5장·기본1152×1440을 받지만 실제 구도·제품 보존과 서비스 입력 연결은 검증해야 한다. 입력 파일 용량·해상도 무제한 요구는 현재 운영 상한과 별도 합의한다.
- **SSOT-05~10:** 기획 사전 조사 → 카피 1개 → 사용자 카피 검토 → 이미지 1개 → 사용자 이미지 검토 → 최종 한글 합성과 캡션·태그 출력의 직렬 MVP를 목표로 한다. 카피 1개 생성과 caption/hashtags 필드는 이미 지원하지만 기본값·서비스 출력 연결은 다르다. 제품 레이어 승인은 생성 후 사용자 이미지 승인과 별개다.
- **SSOT-11:** 카테고리를 먼저 선택시키지 않고 다양한 화장품 자료를 모아 사후 분류한다. 약30제품은 수집 방안이며 제품당2~5장 적용 시60~150장이라는 준비 규모 추정이다. 확정 수량·현재 확보량·품질 합격 기준으로 표시하지 않는다.
- **SSOT-12:** 텍스트 김다혜·이미지 pi의 역할은 유지한다. API·자산·승인 UI·렌더러·인프라·PM 인수 담당과 실제 서비스 계약의 수락은 별도로 확인한다.
- 부분 수정 UI·다중 시안·3:4와 비율 선택·병렬/이미지 우선 생성·다중 플랫폼은 MVP 이후 검토 대상이다. 기존 내부 revision/cache·복수 카피 생성 능력을 삭제해야 한다는 뜻은 아니다.
