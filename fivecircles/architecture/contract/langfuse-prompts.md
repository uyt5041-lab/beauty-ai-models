# B12 · 화장품 프리셋 실비교와 Langfuse 프롬프트 관리

작성일: 2026-10-23. 사용자 승인: 새 프롬프트로 3종을 각 1장 실제 생성하고 Langfuse로 관리한다.

## 입력과 출력

- 입력: 동일한 가상 세럼 원본 PNG, `clean_studio` / `premium_minimal` / `vivid_pop`, 동일한 오른쪽 제품 배치, 1152×1440, medium 품질.
- 출력: OpenAI 편집 API 각 1회, 총 3회. PNG·요청 스냅샷·제공자 사용량·Langfuse 버전/관찰 기록·비교 보고서를 저장한다.
- 예: 클린 스튜디오 버전 1을 읽고 제품 설명과 배치를 채운 최종 문장을 요청에 고정한다. 이후 원격 production 라벨이 버전 2로 바뀌어도 대기 중인 요청은 버전 1 문장으로 실행한다.

## 변경 범위

- Langfuse의 `beautyai/cosmetics` 아래에 매개변수가 있는 text 프롬프트 3개를 등록한다. production 라벨 조회와 정확한 버전 조회를 지원한다.
- 선택한 이름·버전·최종 문장·해시를 `managed_prompt` 스냅샷으로 요청에 포함한다. 없는 경우 기존 직렬화와 해시를 보존한다.
- 어댑터는 고정된 최종 문장을 사용한다. 기존 라이브 허용·예산·단일 제출·자산 검증 정책을 유지한다.
- 실행 기록은 프롬프트 버전과 연결한다. 이미지 바이트나 비밀키 대신 자산 해시, 모델, 요청 해시, 사용량, 추정 비용을 기록한다. 실제 청구액은 별도 확인 전 null이다.
- 관찰 기록 실패가 이미지 API 재호출이나 성공 이미지 소실로 이어지지 않는다. 원격 조회 실패 시 새 유료 작업을 시작하지 않는다.
- 꽃을 추가하는 기본 지시도 꽃 금지도 없다. 텍스트 담당 김다혜의 LLM 업무와 광고 카피 생성은 이번 구현에 포함하지 않는다.

## 검증과 범위 제한

- 실제 비교는 같은 원본과 설정으로 정확히 3회만 수행한다. 오류/응답 유실은 영수증에 남기고 자동 재시도하지 않는다.
- 관리 프롬프트 고정·해시 변경·기존 요청 호환·기록 실패 격리·비밀 미출력은 모의 테스트로 확인한다.
- 결과는 가상 무상표 제품의 시각 비교다. 실제 브랜드 라벨 보존이나 팀 인수 완료를 뜻하지 않는다.
- 생성 이미지·환경변수·런타임 DB는 Git에서 제외한다. 공개 문서에는 안전한 요약만 기록한다.
