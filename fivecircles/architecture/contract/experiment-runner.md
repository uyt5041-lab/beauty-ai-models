# 실제품 실험 실행기 계약

2026-10-23 · 구현 전 계약. 담당 pi. 이번 실행은 유료 이미지 호출 없이 구현과 모의 검증만 한다.

## 범위

사용자가 요청한 순서대로 입력 처리 → 프리셋·버전 → 호출 제한 → 미리보기·통합 검증을 진행한다. 각 단계의 테스트가 통과해야 다음 구현을 시작한다. 실패하면 자동 수정·재시도 없이 중단한다. 이 사용자 지시가 스킬의 재시도 절차보다 우선한다.

- 입력: 동일 제품 사진 2~5장, 배경 참고 0~5장. 첫 제품 사진이 주 시점이다. 파일 장수 검증은 동일 제품 확인이나 광고 사용 승인과 다르다.
- JPEG/PNG/WebP를 기존 자산 저장소로 정규화한다. EXIF 방향과 색 프로필을 처리하고 원본·정규화 SHA를 모두 남긴다. 기존 20MiB/16MP 제한을 유지한다. 중복 파일과 역할 중복을 거부한다.
- 프리셋은 명시적으로 선택한다. 로컬 `cosmetics-v1` 또는 로컬에 저장한 정확한 Langfuse 이름·정수 버전을 사용한다. 준비·실행 중 production 재조회나 자동 게시를 하지 않는다. 원격 버전 수집은 별도 명시 작업이다.
- 미리보기는 입력·요청·최종 제공자 프롬프트·버전·모델·크기·품질·호출 상한·고정 작업 ID를 JSON과 한글 HTML로 저장한다. 네트워크·환경 키·W&B 업로드가 필요하지 않다.
- 실제 실행은 미리보기의 고정 계획을 소비한다. 계획·입력 해시가 다르면 거부한다. 호출 상한은 계획에 고정한다. 시도는 전송 전에 영속 기록한다. 재시작·중복 실행으로 상한을 초기화하지 않는다.
- 한 건이 실패하거나 전송 여부가 미확인이면 후속 작업을 멈춘다. 자동 재시도하지 않는다. 예약된 시도 수는 확정 청구 횟수와 다르다.
- 실제 비용·팀 잔액은 미확인 시 null이다. 호출 횟수 상한은 달러 청구 상한이나 공유 예산 확인을 대신하지 않는다.
- 원본·정규화 사진·실행 결과는 로컬 uploads/outputs 안에 둔다. 공개 Git·Langfuse·W&B에 자동 업로드하지 않는다.

예: 제품 사진 2장 + 배경 참고 1장 + vivid_pop + 지정 버전 + 최대 1회 → 호출 전 미리보기 1건. 별도 실행 시 최대 한 번 시도한다. 다른 제품용 고정 묘사가 있는 버전은 사용 전에 프롬프트 본문에서 확인한다.

## 호환성과 검증

기존 래퍼의 단일 제품 편집·누끼 계약은 유지한다. 새 실제품 실행기에만 제품 최소 2장 조건을 적용한다. 기존 실험과 프롬프트 버전·영수증은 덮어쓰지 않는다. 이번 범위는 이미지 품질 승인, 팀 키 확인, 서비스 통합, 유료 실험이 아니다.
