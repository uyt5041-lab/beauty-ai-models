# B14 · W&B 이미지 실험 기록과 임시 평가 계약

작성: 2026-10-23. 사용자 요청: Langfuse 유지, 기존 이미지·프롬프트 버전·시간·비용을 W&B에 업로드하여 비교, 팀 Notion 목표와 PM 서비스 평가 체크리스트에 맞는 임시 평가 기준 설정.

## 범위와 완료 조건

- Langfuse의 프롬프트 원본·버전·generation 관찰은 유지한다. W&B는 이미지 실험 결과·비교표·평가 계획을 보관한다.
- 새 생성/편집/누끼 API 호출 없이 저장된 실제 API 및 과거 실제 로컬 모델 실행을 수집한다. 모의 샘플과 백업 복제는 실제 실행 건수에 포함하지 않는다.
- 한 기록은 한 실제 실행이다. 결과 이미지가 같아도 별도 실제 실행의 시간은 보존한다. 실패 실행은 결과 없음으로 구분한다.
- 프롬프트는 당시 request/파일에서만 복구한다. 현재 템플릿으로 과거 프롬프트나 버전을 추정하지 않는다.
- 기존 Langfuse URL을 연결한다. 저장된 이미지·프롬프트·정규화 메타데이터만 명시적으로 업로드하며 env, DB 원본, 원문 Notion 자료, 전체 소스 폴더는 업로드하지 않는다.
- W&B에 실제 저장 후 run·메타데이터·비교표·artifact를 다시 읽어 확인한 경우에만 업로드 완료로 기록한다. 재실행은 안정 ID와 콘텐츠 해시로 중복·충돌을 확인한다.
- 잠정 평가 기준은 `PROVISIONAL_NOT_TEAM_APPROVED`로 버전 관리한다. 표본 계획은 실제 확보·평가 완료를 뜻하지 않는다. 미검수 결과는 자동 합격 처리하지 않는다.
- 사용자 추가 지시로 종합 비중은 이미지 품질40%·FinOps40%·서비스20%다. 광고당 총원가·회피 가능한 생산 낭비·공유 팀 예산·청구 대조는 각각 필수 조건이며, 비용 정보 미확인은 FinOps 통과나 출시로 바꾸지 않는다.

## 입출력과 경계

입력: 로컬 BeautyAI 출력 루트의 알려진 receipt, 당시 request, 원본·결과 이미지. 이미지 경로와 해시를 검증한다.

출력: 정규화 experiment JSON, 각 실행의 W&B run/이미지 artifact, 전체 비교 Table, 임시 평가계획 artifact, 로컬 업로드 receipt와 원격 readback 결과.

예: `vivid_pop / v1 / 원본 A / 결과 B / 19.258초 / 추정 $0.026675`와 `vivid_pop / v2 / 같은 원본 A / 결과 C / 19.517초 / 추정 $0.027410`를 별도 행으로 비교한다. 두 시간의 측정 구간이 다르면 그 구간을 함께 표시한다. 버전·계산값의 최종 값은 원본 기록을 따른다.

- `started_at`은 원 실행 시각, `imported_at`은 W&B 업로드 시각이다.
- `estimated_cost_usd`와 `actual_cost_usd`는 별도다. 미확인 청구액은 null이며 0으로 바꾸지 않는다. 로컬 모델 비용은 측정되지 않았으면 null이다.
- 원본에 추정치가 없고 당시 사용량·모델이 일치하는 초기 API3건은 B12에 저장된 단가로 재구성한다. 계산 근거와 `RECONSTRUCTED_WITH_RECORDED_B12_RATES`를 붙이고 실제 청구로 표시하지 않는다.
- 팀 제공 OpenAI $30는 안내상 한도다. 사용한 키의 팀 계정 여부와 전체 잔액이 확인되지 않았으므로 일부 이미지 실험비를 빼서 팀 잔액을 만들지 않는다. R&D 실험비와 생산 실패/재시도 낭비도 구분한다.
- SDK가 null summary를 생략할 수 있으므로 known/status 필드와 JSON artifact의 명시적 null을 함께 유지한다.
- 무상표 가상 제품은 smoke 자료다. 실제품 holdout·라벨 보존 평가의 표본 수에 넣지 않는다.
- 공개 Git에는 코드·임시 기준·빈 manifest 예제·문서만 둔다. 실제 이미지, 업로드 영수증, 로컬 W&B 캐시는 ignored output에 둔다.

## 검증

- collector: 과거 프롬프트/시간 출처, 경로 탈출·해시 불일치, 중복·실패 기록, 누락값 처리.
- publisher: 실제 이미지 호출 없이 명시된 파일만 전송, 동일 ID 재실행과 내용 충돌, 비밀값 비노출, null 비용·원 시각 유지.
- 평가: 미검수/결측·2인 불일치·치명 결함·임계값·N/A·표본 출처·홀드아웃 분리.
- 전체 Python 회귀·FiveCircles 검사·두 로컬 소스 동기화. 실제 W&B 원격 재조회는 mock 테스트와 별도 기록.

## 현재 범위 밖

신규 이미지 생성·유료 자동 judge·팀 합의 확정·팀 Notion 원본 수정·다른 담당자 기능 구현·API 제공자 변경·자동 Git push는 포함하지 않는다.
