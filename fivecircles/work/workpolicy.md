# 작업 기록 정책

- 구현 전 관련 요구사항/계약·원본 TODO·learn-from-log를 확인한다.
- 의도·변경 범위·검증 계획을 worklog에 기록하고 작업한다.
- 완료 후 update와 원본 TODO의 실제 완료 상태를 갱신한다. 긴 증거는 중복 복사하지 않고 링크한다.
- 검증 실패는 test/errorlogs에 날짜/시각·명령·실패·원인·수정·재검증을 기록한다.
- 해결된 기술 교훈은 test/learn-from-log, 반복 운영 실수는 agent/mistakes-arrest에 둔다.
- scoring은 선택 사항이며 작업 권한·완료 판정을 바꾸지 않는다.
- 개인 협업일지 MD/HTML은 별도 브랜치에 요청 시 작성한다. 이 폴더는 개발 근거 기록이다.
