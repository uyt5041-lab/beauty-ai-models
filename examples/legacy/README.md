# 과거 실행 입력

`bright_flower_prompt.json`은2026-10-22 B7/B9 로컬 모델 실험 입력을 보존한 파일이다. 현재 화장품 광고 프리셋이나 기본 예제로 사용하지 않는다.

2026-10-23 사용자 정정에 따라 현재 예제는 [cosmetics_brief.json](../cosmetics_brief.json)과 [화장품 프롬프트 가이드](../../docs/cosmeticsPromptGuide.md)를 사용한다. 보존한 로컬 SDXL 경로의 예제는 [bright_cosmetics_prompt.json](../bright_cosmetics_prompt.json)이다.
